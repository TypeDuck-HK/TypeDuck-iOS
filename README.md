## 功能 Features

- 以粵拼輸入文字，候選列會顯示候選詞、粵拼及翻譯。<br>
  Type in Jyutping romanisation and see candidates, Jyutping and translations appear in the candidate bar.
- 向下掃一下帶有 ⓘ 圖示之候選詞可開啟辭典版面並瀏覽詞條詳細資訊。<br>
  Swipe down on a candidate with an ⓘ icon to open dictionary panel and view entry details.
- 反查功能：遇到不諳讀音／粵拼串法之字詞時，長按 <kbd>r</kbd> 鍵可臨時切換至其他輸入法輸入一個字詞，輸入完成後會自動返回。<br>
  Reverse Lookup feature: Not sure about a character/word's pronunciation or Jyutping spelling? Press and hold the <kbd>r</kbd> key to temporarily switch to another input method. After you type the character/word, the app will automatically switch back to Jyutping.
- 應用程式內可更改翻譯語言、顯示項目等設定。<br>
  You can change settings such as translation languages and display options in the app.

欲觀看圖解並了解更多功能，請瀏覽 [typeduck.hk/features](https://typeduck.hk/features/) 並參閲應用程式內指南。<br>
Visit [typeduck.hk/features](https://typeduck.hk/features/) and check out the in-app guides to view illustrative demos and learn about other features.
